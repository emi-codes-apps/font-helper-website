Help and troubleshooting for Font Helper 🎨

Getting started

  1. Open a Google Docs document.
  2. Launch Font Helper from the Extensions/Add-ons menu or the location shown by your installed version.
  3. Grant the requested Google permissions if prompted.
  4. Open the Font Helper sidebar or interface and use the font or formatting tools you need.

Common troubleshooting

Font Helper does not appear in my document

Refresh the Google Docs tab, reopen the document, and check the Extensions/Add-ons menu. If it was installed while the document was already open, a refresh may be required.

I was asked to authorize the app

Google authorization is required for features that interact with your document. Review the requested permissions and continue only if you are comfortable granting them.

The sidebar opens but a feature does nothing

Try selecting the relevant text again, refresh the document, and reopen Font Helper. If the issue persists, send an issue report with the exact steps that reproduce it.

A font or formatting result looks different than expected

Google Docs can apply inherited paragraph, character, and style formatting. Try the same action on a small test selection and include the starting style and expected result in your report.

How do I revoke Font Helper's access?

You can remove the add-on and revoke its access from the third-party connections or security section of your Google Account.

Does Font Helper store my document text?

Font Helper is designed to process the document information needed for the requested feature within the Google environment and does not intentionally store document contents on a separate developer-operated server. See the Privacy Policy for details.
