# Font Helper 🎨 — GitHub Pages site

Static support/policy website for the Font Helper Google Docs extension.

## Pages included

- `index.html` — landing page
- `privacy.html` — Privacy Policy
- `terms.html` — Terms of Service
- `help.html` — Help URL
- `support.html` — Support URL
- `report-issue.html` — Report Issue URL
- `404.html` — fallback page

Support email: `emi.codes.apps@gmail.com`

## Publish with GitHub Pages

1. Create a GitHub repository, for example `font-helper-site`.
2. Upload **the contents of this folder** to the repository root.
3. Commit the files to the `main` branch.
4. In GitHub, open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select `main` and `/ (root)`, then save.
7. Wait for GitHub Pages to publish the site.

If your GitHub username is `YOURNAME` and the repository is `font-helper-site`,
your URLs will normally be:

- Home: `https://YOURNAME.github.io/font-helper-site/`
- Terms: `https://YOURNAME.github.io/font-helper-site/terms.html`
- Privacy: `https://YOURNAME.github.io/font-helper-site/privacy.html`
- Support: `https://YOURNAME.github.io/font-helper-site/support.html`
- Help: `https://YOURNAME.github.io/font-helper-site/help.html`
- Report issue: `https://YOURNAME.github.io/font-helper-site/report-issue.html`

## Notes

The issue-report page is fully static. It opens the user's email application with a
pre-filled email to `emi.codes.apps@gmail.com`; it does not require a backend server.

The Privacy Policy includes Google's Limited Use language for Google API user data.
Review the policy if Font Helper's actual permissions or data-handling behaviour changes.
